# House Price Prediction

**Проект по прогнозированию стоимости жилой недвижимости с помощью линейной регрессии и регуляризации.**

## Постановка задачи и актуальность

Задача — предсказать цену продажи дома (`SalePrice`) по его характеристикам: расположению, площади, возрасту, качеству и другим признакам. Такая оценка может использоваться для первичного сравнения объектов и аналитики рынка недвижимости.

## Данные

[House Prices — Advanced Regression Techniques (Kaggle)](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).

Данные не включены в репозиторий. Исходный ноутбук загружает `train.csv`, `test.csv` и `sample_submission.csv` из Google Drive; пути при необходимости нужно адаптировать.

## Подход

1. Разведочный анализ цен, признаков и пропусков.
2. Разделение данных на обучающую и отложенную выборки.
3. Предобработка: медианное заполнение числовых пропусков, масштабирование и one-hot encoding категорий.
4. Сравнение **Linear Regression, Ridge, Lasso, ElasticNet**.
5. Исследование зависимости RMSE и коэффициентов от `alpha`.
6. Формирование прогнозов в формате Kaggle.

## Метрики

Основная метрика — **RMSE на логарифмах цен**: модели обучаются предсказывать `log(SalePrice)`, а квадратичная ошибка сильнее штрафует крупные отклонения. R² может служить дополнительной характеристикой, но не является основным критерием в сохранённом анализе. RMSE в логарифмическом масштабе не измеряется в долларах.

## Ограничения

- Для подбора `alpha` в исходном исследовании использовалась отложенная выборка, поэтому минимальную RMSE нельзя считать независимой финальной оценкой.
- Промежуточный вариант ElasticNet сохраняет логарифмы цен; итоговый вариант Ridge применяет `np.exp` для восстановления цен.
- Все **code cells и их outputs сохранены без изменений**. Повторное обучение и проверка запуска в новом окружении не проводились.
